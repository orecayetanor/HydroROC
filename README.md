# HydroROC
https://www.paypal.com/ncp/payment/T4U45UF6XYEJ8
**HydroROC** es un complemento para QGIS orientado al análisis hidrológico de cuencas y a la automatización de procedimientos de procesamiento hidrológico.

## Versión 0.4.3

Esta versión incorpora tres herramientas en el proveedor de Processing de HydroROC:

1. **Delimitación automática de cuencas**
2. **Parámetros I – Geometría, forma y relieve**
3. **Parámetros II – Red de drenaje y tiempo de concentración**

## Requisitos

- QGIS 3.28 o superior.
- Proveedores y herramientas de procesamiento requeridos por los algoritmos de HydroROC.
- Para los procesos basados en modelos de elevación, se recomienda trabajar con sistemas de coordenadas proyectadas en metros.

## Instalación

Durante la etapa de desarrollo, HydroROC puede instalarse desde un archivo ZIP:

1. Abrir QGIS.
2. Ir a **Complementos > Administrar e instalar complementos**.
3. Seleccionar **Instalar a partir de ZIP**.
4. Seleccionar el archivo `HydroROC-0.4.3.zip`.
5. Instalar y verificar el proveedor **HydroROC** en la Caja de herramientas de Procesos.
